# Security policy

Non aprire issue pubbliche contenenti dati personali, configurazioni interne,
percorsi di rete o dettagli di un'installazione reale. Le segnalazioni devono
essere riproducibili usando esclusivamente il dataset sintetico della demo.

La repository non distribuisce credenziali né file `.env`. Se un segreto viene
committato per errore, va revocato all'origine oltre a essere rimosso dalla
cronologia Git.
