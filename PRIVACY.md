# Regole per i dati della demo

Questa repository deve contenere esclusivamente dati sintetici.

Non aggiungere:

- database SQLite generati durante l'uso;
- file di configurazione con percorsi locali o di rete;
- backup, log, esportazioni Word/Excel o pacchetti diagnostici;
- nomi di persone, società o reparti reali;
- numeri di chiavi, radio, sigilli, buste o inventari reali;
- fotografie, planimetrie, loghi o documenti dell'ambiente operativo;
- credenziali, token, password o chiavi private.

Per aggiungere nuovi esempi, usare nomi chiaramente fittizi e identificativi
con prefisso `DEMO-`. I dati runtime sono esclusi da Git tramite `.gitignore`.
